# Gekende beperkingen van de proof of concept

Stand 26 oktober 2026. Bijgewerkt bij elke release (zie changelog).

## Bronnen

| Beperking                                                                                                                                                                                    | Gevolg                                                                                                                                                  | Route                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Getty (AAT, ULAN, TGN) weigert of vertraagt verzoeken vanaf het Laravel Cloud-netwerk (HTTP 403 of time-out); vanaf andere netwerken antwoordt Getty soms met "service temporarily degraded" | de drie Getty-bronnen tonen "niet bereikbaar"; de rest van de zoekvraag gaat door                                                                       | opvolgen met Getty; eventueel een eigen kopie van de maandelijkse Getty-dumps hosten                 |
| Thesaurus Onroerend Erfgoed en GeoNames hebben geen SPARQL-endpoint                                                                                                                          | nog niet aangesloten (status "in voorbereiding")                                                                                                        | door meemoo gehoste endpoint vanuit de RDF-dumps (gepland)                                           |
| Visual Name Authority, ODIS, Directory of Belgian Photographers, BALaT/MetaBelgica en de MoMu-thesaurus (Opentheso) publiceren nog geen LOD via SPARQL                                       | enkel als kandidaat gedocumenteerd (intakes in `bronnen/`); personen uit ODIS, FOMU en BALaT zijn wel vindbaar via de Wikidata-bron "personen (België)" | partnerroute per bron, zie de intakes                                                                |
| VIAF heeft geen SPARQL-endpoint                                                                                                                                                              | VIAF-identifiers verschijnen als overeenkomstige term bij Wikidata-personen, niet als eigen bron                                                        | eigen endpoint uit een gefilterde dump, of kandidaat houden                                          |
| De Gentse erfgoedthesaurus bevat dezelfde naam in meerdere deelvocabulaires (bv. drie keer "Mariakerke") en zoekt op deelstring ("Ieper" vindt ook "rotatiepers")                            | dubbele of verrassende treffers in die bron                                                                                                             | woordgrensmatching in het sjabloon; dubbels zijn inhoud van de bron (geen deduplicatie, bestek §3.2) |
| De licenties van VTMK en de Gentse data staan niet expliciet op de datapagina's                                                                                                              | hergebruik moet nog bevestigd worden                                                                                                                    | bevestigen met MoMu en Stad Gent                                                                     |

## Functionaliteit

| Beperking                                                      | Toelichting                                                                                                                                                                                                                                                           |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hiërarchie: enkel bredere/nauwere/gerelateerde termen per term | het volledige pad (broodkruimel) en boomnavigatie per bron (`path`, `browse`) zijn in ontwikkeling                                                                                                                                                                    |
| Resultaatcache                                                 | herhaalde identieke vragen worden tot 2 minuten (zoeken) en 10 minuten (lookup) uit een cache beantwoord; dat wijkt af van "geen caching" (F2.12) en moet met meemoo afgestemd worden. Stuur `Cache-Control: no-cache` voor een live antwoord; TTL 0 zet de cache uit |
| Zoekwidget                                                     | in beta; de API en het script zijn stabiel, de configuratie kan nog wijzigen                                                                                                                                                                                          |
| Feedbackknop                                                   | tijdelijk, voor de testrondes                                                                                                                                                                                                                                         |
| Rapportage aan bronhouders                                     | basis aanwezig (statusmonitor met responstijden en fouten); het maandrapport is in ontwikkeling                                                                                                                                                                       |
| Reconciliation API                                             | buiten de MVP (bestek §3.2)                                                                                                                                                                                                                                           |
| Geen deduplicatie, samenvoeging of export                      | bewust buiten scope (bestek §3.2)                                                                                                                                                                                                                                     |
| Meertaligheid                                                  | hangt af van de bron; het Termennetwerk vertaalt niets                                                                                                                                                                                                                |
| Authenticatie                                                  | de API is publiek zonder sleutel; rate limiting en optionele API-sleutels zijn voorzien voor de productieomgeving                                                                                                                                                     |
